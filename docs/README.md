## 📝 How to Update Documentation

### When to update docs
- ✅ After implementing a feature
- ✅ When fixing a bug with context
- ✅ When changing architecture
- ✅ When adding new endpoints
- ✅ When updating dependencies

### How to update docs
1. Find relevant doc file
2. Update content with changes
3. Update "Last Updated" date
4. Commit with message: `docs: update [section]`
5. Include in PR description

### Creating new docs
1. Check [Documentation Index](./DOCUMENTATION_INDEX.md) for structure
2. Create file in appropriate folder
3. Add frontmatter: `# Title`, `**Last Updated:** Date`
4. Add to relevant index
5. Link from related docs
